# Create a Kira Issue

1. Check `.github/ISSUE_TEMPLATE/` for a matching template. If none exists, write a concise issue with observed behavior, expected behavior, reproduction or evidence, impact, and proposed direction. State unknown details as unknown.
2. Use a clear title with a Kira scope from `AGENTS.md` when the affected module is known. Resolve the repository from its Git remote or connected GitHub context.
3. Submit through the connected GitHub tool or `gh` only when the user asked to file the issue. Do not invent labels or create duplicate issues. Report the issue URL.
