Streaming Debug Tool

Mở file này và chat với "hello" để xem logs chi tiết.

Sau đó copy toàn bộ console logs (Ctrl+Shift+J) và gửi cho tôi.

Hoặc copy logs từ console của trang chính:

  1. Mở trang http://localhost:3001/conversation
  2. Mở DevTools (F12)
  3. Tab Console
  4. Clear console (Ctrl+L)
  5. Chat "hello"
  6. Tìm các logs bắt đầu bằng: [STREAM], [buildThinkingHierarchy], [ThinkingHierarchy]

Các logs cần tìm:

  • [STREAM] Chunk received: - Backend emit chunk gì?
  • [STREAM] Thinking appended: - Thinking buffer được append không?
  • [buildThinkingHierarchy] Built: - Hierarchy được build không?
  • [ThinkingHierarchy] Render: - Component render không?
